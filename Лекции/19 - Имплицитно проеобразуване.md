# Имплицитно проеобразуване

## 📌 Какво ще се прави?

Ще разгледаме имплицитното преобразуване

## 🧠 Бележки

Съществуват различни видове преобразувания, като ние ще ги разгледаме стъпка по стъпка.
Първо ще започнем с имплицитното преобразуване.
За целта ще създадем следната променлива.

> [!code] C# Създаване на int променлива
> ```csharp
> int myInt = 13;
> ```

Сега ние можем да имаме `double` и тази променлива може да бъде равна на `int` променливата.

> [!code] C# Double п
> ```csharp
> int age = 25;
> string name = "Vladislav";
>
> Console.WriteLine($"Hello, {name}!");
> Console.WriteLine($"Age: {age}");
> ```
